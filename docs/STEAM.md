# Пятимирье в Steam: как выпустить

Всё, что можно подготовить в репозитории, уже готово: сборка с Steamworks,
скрипты SteamPipe, картинки для страницы магазина и тексты описания.
Ниже шаги, которые делаются в кабинете Steamworks вручную.

## 1. Регистрация разработчика

1. Зайти на [partner.steamgames.com](https://partner.steamgames.com) и
   оформить аккаунт Steamworks: соглашение, банковские и налоговые данные,
   подтверждение личности.
2. Оплатить Steam Direct — взнос за одно приложение (100 $, возвращается после
   первых 1000 $ выручки).
3. После оплаты появится **AppID** игры и номера депо. Дальше их нужно
   подставить в сборку и скрипты.

Между оплатой и выходом должно пройти не меньше 30 дней. Страница «Скоро
выйдет» должна провисеть не меньше двух недель, и обе проверки Valve
(страница и сборка) занимают несколько дней.

## 2. Сборка

Steam-версия собирается с тегом `steam`, обычные сборки его не используют:

```sh
STEAM_APPID=1234560 STEAM_SDK=~/steamworks_sdk ./scripts/build-steam.sh
```

* Номер приложения вшивается при сборке
  (`-X github.com/brokendoto/brokengame/internal/platform.SteamAppID=…`).
  По умолчанию стоит `480`: это тестовое приложение Valve (Spacewar), с ним
  интеграцию можно проверить до получения своего номера.
* **Windows:** рядом с `Pyatimirye.exe` должна лежать `steam_api64.dll` из
  Steamworks SDK (`redistributable_bin/win64`). Скрипт копирует её, если
  задан `STEAM_SDK`. Саму DLL в репозиторий класть нельзя по лицензии SDK.
* **Linux и Steam Deck:** библиотека `libsteam_api.so` уже встроена в
  go-steamworks, ничего копировать не нужно. Linux-депо запускается и на
  Steam Deck. Игра управляется геймпадом, масштабируется под экран 1280×800,
  а имя игрока в Steam-сборке берётся из профиля Steam, поэтому клавиатура
  не нужна. Перед подачей на «Steam Deck Verified» стоит пройти меню и
  настройки на самом Deck.
* В CI задача `steam` собирает обе версии и выкладывает их артефактом
  `Pyatimirye-steam`.

Если игру запустить не из Steam, она перезапустится через Steam. Для отладки
это можно выключить переменной окружения `PYATIMIRYE_NO_STEAM_RESTART=1`.
Если Steam не запущен, игра работает как обычная сборка.

## 3. Загрузка через SteamPipe

1. В `steam/scripts/app_build.vdf` и `depot_*.vdf` заменить `480`, `481`
   и `482` на свой AppID и номера депо.
2. В кабинете: **Installation → General** указать запуск
   `Pyatimirye.exe` (Windows) и `pyatimirye` (Linux + SteamOS).
3. Загрузить сборку:

   ```sh
   steamcmd +login <логин> +run_app_build $(pwd)/steam/scripts/app_build.vdf +quit
   ```

4. В **SteamPipe → Builds** назначить сборку ветке `default` (или сначала
   закрытой ветке `beta` для тестов).

## 4. Достижения

В **Stats & Achievements** завести 19 достижений. API-имя должно совпадать с
идентификатором в игре (`internal/achieve`), иначе Steam их не откроет.
Тест `TestSteamAPINames` проверяет, что имена годятся для Steam. Иконки
256×256 (цветная и серая) можно снять с экрана «Достижения» в игре.

| API-имя | Название | Описание | Скрытое |
|---|---|---|---|
| `first_win` | Первый выход | Пройди любой уровень |  |
| `gold` | Золотая лихорадка | Получи золотую медаль |  |
| `no_hit` | Ни царапины | Пройди уровень, ни разу не получив удар |  |
| `max_combo` | Серия ×3 | Собери 9 предметов подряд без перерыва |  |
| `speedrun` | Быстрее эталона | Пройди уровень быстрее эталонного времени |  |
| `hard_finale` | Хардкор | Пройди 8-й уровень любого мира на сложной |  |
| `daily` | Испытание принято | Пройди испытание дня |  |
| `beat_ghost` | Обогнать призрака | Набери больше очков, чем призрак соперника |  |
| `duel_win` | Дуэлянт | Выиграй дуэль |  |
| `world_mine` | Покоритель шахты | Пройди все уровни Кристальной шахты |  |
| `world_forest` | Хозяйка леса | Пройди все уровни Осеннего леса |  |
| `world_temple` | Путь самурая | Пройди все уровни Ночного храма |  |
| `world_front` | Ас передовой | Пройди все уровни Руин передовой |  |
| `world_space` | Звёздный странник | Пройди все уровни Открытого космоса |  |
| `gold_world` | Золотой мир | Получи золото на всех уровнях одного мира |  |
| `all_golden` | Ни жёлудя врагу | Собери все золотые жёлуди на уровне леса |  |
| `pure_soul` | Чистая душа | Пройди уровень храма, не тронув проклятых душ |  |

| `robot` | Я, робот | Посмотри, как играет автопилот | да |

Игра сама переносит в Steam достижения, полученные до появления Steam (при
каждом запуске сверяет профиль), так что прогресс с бесплатной версии не
теряется.

## 5. Что ещё умеет Steam-сборка

* Имя игрока для таблиц рекордов берётся из профиля Steam.
* Друзья видят статус: «В меню», название уровня или «Дуэль · …» (ключ
  rich presence `status`).
* В меню рядом с номером версии написано «Steam».

**Онлайн-таблицы рекордов** пока остаются локальными: библиотека
go-steamworks, через которую игра работает со Steam, не поддерживает
leaderboards. Когда поддержка появится (или если добавить её самим), её
нужно реализовать за интерфейсом `save.Leaderboard`. Записи забегов уже
проверяются пересимуляцией, а это основа защиты от накруток.

## 6. Страница магазина

* **Картинки** лежат в `steam/art/`. Они собираются командой
  `go run ./cmd/storeart` из скриншотов в `docs/screens`:

  | Файл | Размер | Где в кабинете |
  |---|---|---|
  | `header_capsule.png` | 920×430 | Store Assets → Header Capsule |
  | `small_capsule.png` | 462×174 | Small Capsule |
  | `main_capsule.png` | 1232×706 | Main Capsule |
  | `vertical_capsule.png` | 748×896 | Vertical Capsule |
  | `page_background.png` | 1438×810 | Page Background |
  | `library_capsule.png` | 600×900 | Library Assets → Capsule |
  | `library_header.png` | 920×430 | Library Header |
  | `library_hero.png` | 3840×1240 | Library Hero |
  | `library_logo.png` | 1280×720, прозрачный фон | Library Logo |

  Это рабочие варианты. Перед выходом капсулы лучше перерисовать вручную или
  заказать художнику, потому что капсула сильнее всего влияет на клики.
  Library Hero собран из скриншотов, растянутых до 4K, и на большом экране
  будет мягким.
* **Скриншоты** (не меньше пяти, 1920×1080 или 1280×720): `docs/screens`.
* **Тексты** на русском и английском: [`steam/store-text.md`](../steam/store-text.md).
* **Трейлер** снимается с экрана (например, OBS) и загружается в кабинет.
* **Возрастной рейтинг:** анкета IARC в кабинете. Насилия и покупок в игре
  нет.

## 7. Перед кнопкой «Выпустить»

- [ ] Сборка прошла проверку Valve, достижения открываются на тестовой ветке
- [ ] Проверено на Steam Deck (или в режиме Big Picture с геймпадом)
- [ ] Страница прошла проверку и висит в статусе «Скоро выйдет» ≥ 2 недель
- [ ] Цена и региональные цены заданы
